# TRAE 规则注入套件（扩展）

在 TRAE 里把一套「行为契约」写进全局规则目录，让助手按指定形态输出。

## 命令

命令面板（`Ctrl+Shift+P` / `Cmd+Shift+P`）里搜 `TRAE 规则注入`：

| 命令 | 作用 |
| --- | --- |
| 安装全局规则 | 把契约写进 `~/.trae-cn/user_rules/rule-trae-purge-kit.md`；旧文件自动备份 |
| 卸载并还原 | 有备份就还原备份，没有就删掉本扩展自己写的那个文件 |
| 查看状态 | 显示规则路径、指纹、是否被改动过、备份数量 |
| 自检 | 四项断言：文件在不在、双标记齐不齐、指纹对不对、正文有没有被改过 |
| 打开规则文件 | 在编辑器里打开规则文件 |

## 它会动什么

- 写一个文件：`~/.trae-cn/user_rules/rule-trae-purge-kit.md`
- 备份一个文件：同名 `.bak-<时间戳>`
- 写一个状态文件：`~/.trae-purge-kit/state.json`

**不会**动 TRAE 的安装目录、二进制、其它规则文件，也不会联网。

## 装完要做两件事

1. 完全退出 TRAE（含托盘与后台进程），重新打开。
2. 开一个**新**对话——旧对话的上下文不会补上规则。

## 关于 979 / 983

TRAE 云端的内容安全（错误码 979 / 983）在服务端判定，规则改不动它。
要真正绕开，请按「设置 > 模型管理 > 添加模型 > 自定义模型（OpenAI 兼容）」接一个你自己的模型服务，
然后在聊天窗口右上角切到那个模型。详见套件里的 `docs/BYPASS-LAYERS.md`。
